Mock Anything is a free, non-commercial passion project run by Shreyas Sawant, an independent developer. This page covers the website at mockanything.dev and the Mock Anything tool (the command-line program and MCP server). Contact: shreyassaw@gmail.com.

The short version

  • The website sets no cookies, uses no analytics or tracking, and loads nothing from other websites.
  • The tool runs on your computer, has no telemetry, and does not send what you do to us.
  • We don't sell or share personal information, and we don't have accounts, forms or mailing lists.

The tool

Mock Anything runs locally. Twins keep their data in memory on your computer and forget it when they stop. Nothing you send to a twin is sent to us. The tool makes network requests only in these cases:

  • Installing or updating it through npm (governed by npm's terms and privacy policy).
  • Looking up an API by name: it downloads the public directory from api.apis.guru and then the API description from the address listed there. Those servers see your IP address. Downloads are cached in ~/.mockanything/cache.
  • Loading a URL you give it (an API description, or a documentation page when your agent uses twin_from_docs). That server sees your IP address.
  • Webhooks you configure, which go to addresses on your own machine unless you allow other hosts.

The tool masks keys and card numbers in its local logs and dashboard. Please use test data only.
